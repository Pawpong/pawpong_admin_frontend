# 놀이터 결제 어드민

`/billing`에서 서버 상품 카탈로그, 기능별 이용권 정책, 구매 원장, 감사 이벤트를 관리한다. 백엔드 `.kiro/specs/in-app-purchase/api-contract.md`에 합의한 `/api/iap-admin` 계약을 사용한다.

상품 생성은 기본 비활성·판매 중지·스토어 미등록이다. 운영자가 상품 코드, 스토어 ID, 소모성/비소모성/구독 유형, 혜택·공통 creditKey·수량, 판매 여부를 설정한다. 가격과 실제 구독 기간은 스토어에서 관리한다. 스토어 상품 등록/심사 없이 내부 카탈로그만으로 판매되지 않는다. 기존 판매 상품의 지급 정의 변경은 서버가 거절하며 원장을 보존하기 위해 삭제는 보관 처리로 동작한다.

모든 변경은 사유를 남긴다. 기능별 dailyFreeLimit/creditCost/creditKey/enabled와 미래 기능의 비활성 정책을 설정할 수 있다. 구매·감사 내역은 회원/상품/스토어/기간으로 조회하고, 상세에서 권한 회수·재지급 사유와 타임라인을 확인한다. 권한 조치는 스토어 환불 실행과 별개로 표시한다.

실제 상품·가격·판매 정책은 이 변경에서 운영에 등록하지 않았다. 운영 DB·서버 및 스토어 심사 제출은 수행하지 않는다.

검증: 타입체크, Node 테스트 41개, Vite 빌드 통과. 변경 파일 ESLint 통과. 전체 lint에는 기존 다른 기능 오류가 남아 있다. OpenAPI 계약과 격리된 로컬 서버 브라우저 검증은 완료 후 결과를 갱신한다.
