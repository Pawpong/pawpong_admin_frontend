# 검증 방법

Node 22.15 이상, pnpm 9.15.4.

```sh
pnpm test:contract:update
pnpm test
pnpm typecheck
pnpm build
pnpm lint
```

`test:contract:update`는 공개 개발 OpenAPI를 읽어 관리자·공용 업로드/로그아웃 관련 스키마를 저장한다. URL 또는 로컬 JSON 경로를 인수로 지정할 수도 있다. 민감한 인증 정보는 필요하지 않다.

`pnpm test`: 실제 Axios API 모듈에 네트워크 없는 테스트 어댑터를 사용한 20개 회귀 테스트와 API 호출 131개 / 관리자 operation 119개 계약 검사를 실행한다. 모든 테스트 통과. 빌드와 타입 검사 통과. 기존 lint 미해결 항목은 gaps.md 참고.

브라우저: Orca에서 개발 서버를 열고 명세로 생성한 mock 응답을 실제 API 모듈에 주입해 전체 32개 페이지를 데스크톱 및 폭 390px 프레임에서 순회했다. 런타임 예외, 콘솔 오류, 로딩 실패 문구, 문서 가로 넘침을 확인했다. 테스트용 계정·데이터는 운영 데이터가 아니다.

별도 상호작용 확인: 빈 검색어 저장 차단, 유효 검색어 저장의 mock POST 도달, 이메일 sandbox 미리보기, 필수 이메일 정보 없는 발송 차단, 콘테스트 항목 입력 화면. API 요청의 false·0 값 보존 및 raw HTML 응답은 자동 회귀 테스트로 확인한다.

실제 서버 검증에 필요한 후속 작업: 테스트 관리자 계정으로 로그인하여 역할별 권한, CRUD 후 재조회, 실제 파일 CDN 접근, 이메일/푸시/알림톡 수신, 배포 후 갱신·로그아웃을 검증한다. 이 단계는 완료되지 않았다.

연결 확인: 로컬8080/dev-api/api 서버 모두 응답. 개발용 동일 출처 프록시를 적용한 뒤 브라우저의 실제 인증 오류 응답 수신을 확인했다. 인증되지 않은 401은 로그인 필요 상태이며 성공한 데이터 조회로 계산하지 않는다.
